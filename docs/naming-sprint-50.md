## Methodology

Each candidate is evaluated on:
- **Domain availability:** .com, .io, .ai checked via web search (formal registrar lookup recommended for shortlist)
- **Trademark conflicts:** Web-based USPTO search + comprehensive web search for active companies/products
- **Brand fit:** Approachable/modern feel, loosely functional, no "AI" suffix, works for GraphRAG knowledge management
- **Namespace cleanliness:** How crowded is the name in search results

### Risk Ratings
- 🟢 **LOW** — No active conflicts found, likely registrable
- 🟡 **LOW-MEDIUM** — Minor conflicts in unrelated industries
- 🟠 **MEDIUM** — Some conflicts exist but defensible
- 🔴 **HIGH** — Active conflicts in tech/SaaS/knowledge space — eliminated

### Verification Notes
- USPTO TESS database not directly accessible via automated tools; trademark searches conducted via web search proxies
- Domain availability inferred from web presence; **formal registrar lookup required** before any registration decisions
- Opvio.com confirmed for sale on BrandBucket (premium domain marketplace)
