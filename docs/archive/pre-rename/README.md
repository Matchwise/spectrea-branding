# Archive — pre-rename material (historical record)

> **Historical record (Feb–Mar 2026).** Everything in this directory predates the
> MatchWise → Spectrea rename and is **superseded**. It is retained for
> traceability only — none of it is canon, none of it is referenced by the app,
> the generators, or any published artifact. The canonical brand data is
> `src/data/brand.ts`; per its naming rule, any earlier material using the
> company name as a product or brand name is superseded — Spectrea is the only
> product name.

Contents (all superseded):

- `matchwise-brand-audit.docx` / `matchwise-brand-audit.txt` — the original
  audit that recommended the rename ("MatchWise will become a growing
  liability"). The rename it argued for was executed; the document's other
  recommendations were absorbed or retired by later ratified work.
- `naming-sprint-50.md` — the first 50-candidate naming sprint (recommended
  "Opvio"; does not contain "Spectrea").
- `metaphorical-brand-candidates.md` — a metaphorical-real-word candidate
  sweep from the same sprint cycle.
- `naming-proposal-validated.md` — the validated naming proposal (694
  candidates, sixteen styles) that fed the final decision.
- `naming-ranked-list.md` — a scored ranking in which "Spectrea" placed 35th.
  The final choice weighed factors this scoring did not; the ranking is a
  process artifact, not a verdict on the shipped name.

Archived 2026-08-09 (audit finding D23, decision 28 in
`docs/brand-review-2026-08/ratifications-2026-08-06.md`). Three pure
duplicates/backups (`matchwise-brand-audit (1).docx`,
`naming-proposal-validated.md.bak`, `naming-proposal (1).md`) were deleted in
the same change — git history retains them.
